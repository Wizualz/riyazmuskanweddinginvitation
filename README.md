# Riyaz & Muskan · Nikah Invitation

Single-file invitation page. Everything (curtain frames, images, music) is inside `index.html`.

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` (and this README) to the repository root.
3. Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
4. After a minute the site is live at `https://<username>.github.io/<repo-name>/`.

## Edit the details
Open `index.html`, search for `const CFG=` and change names, dates, venue and contact there.
